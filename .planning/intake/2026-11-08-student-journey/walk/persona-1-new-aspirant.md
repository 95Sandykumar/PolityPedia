## 0. Blocker found first (read this)

**The live Supabase project that the dev server talks to does not have migration 0041. The app code already needs it. Result: every mock list and past-paper list silently shows empty, so Riya can never reach the free sample.**

Proof (all this session):
- `list_migrations` for project `fkcuqwywxpvoxgzszhdq` ends at `0040_ai_finish_server_only`. No `0041`.
- Repo has `supabase/migrations/0041_keep_money_and_scores.sql:131-132` adding `archived_at` to `mock_sets` and `mock_tests`.
- App selects it: `src/lib/mocks/supabase-mocks-client.ts:52-53` (`SET_COLUMNS`, `TEST_COLUMNS` both end in `archived_at`).
- Live REST read with the student token, the exact `SET_COLUMNS` query: HTTP 400 `42703 column mock_sets.archived_at does not exist`. Same for `mock_tests` and `papers`.
- Same token, `select=id,title,status,teacher_id,price_inr` works: HTTP 200, 1 live set `[Demo] UGC NET Political Science Full Mock 1`, 2 tests, test 1 `is_free_sample: true`. So the data is there. The query is what breaks.
- The failure is swallowed: `src/lib/set-access/student-page.ts:46-52` does `.catch(() => [])`. Screen result: Mocks tile shows `0`, Papers tile shows `0` (`p1-05`), and the Mocks page says "No mock tests yet. Your teacher adds them soon." (`p1-06`, string `mockList.none` at `src/lib/i18n.ts:393`).

Fix is outside my scope (apply 0041 to the project, then re-check). Everything below about the mock step is therefore code-read, UNVERIFIED on screen.
