Part IV

Community: the teacher controls who can talk

Broadcast · default

Only the teacher posts. Students read and react.

Like a Telegram channel.

Allow-list

The teacher picks which students can post.

For toppers or helpers.

Open

Every member can post.

Like a Discord room.

  • The database checks every message before it saves it. A student who is not allowed to post cannot post, even with a hacked app.
  • The teacher can delete a message, mute a student or remove a student. Students can report a message.
  • Limits: 1 message every 5 seconds, 2,000 characters. Only the teacher can attach files (5 MB max).
  • V1 has no private messages, between students or between teacher and student. This keeps everyone safe.
  • Live chat uses Supabase Realtime. Your plan includes 500 users online at the same time. Each extra 1,000 costs $10. A phone connects only while that group screen is open.

Part VIII

AI tutor + newsletter

Tutor

It searches the notes, classes and PYQs for the student's exam. Haiku answers from those pieces only and shows source cards, like "Class 14, jump to 12:30". If the answer is not there, it says "not in notes". Free: 5 questions a day. Pro: fair use, 100 a day.

Newsletter

Saturday: Sonnet drafts it from the week's news, new classes and a PYQ. The teacher approves it. Sunday 7 AM IST it goes out, and a "sent" marker stops any double send.

What changes the day we charge money

Vercel Pro needed. The free plan is for non-commercial use only. Upgrade before the first paid student.

Payment checks turn on. Razorpay subscriptions with UPI autopay. Every payment event gets a duplicate check and a signature check, and a daily job compares Razorpay with our database.

The teacher's contract. A paid rival to Adda247 is the real contract risk. Check it before launch day.

Built now, used later: a plan table (free / early / pro) and one database check for "can this student use this feature". Switching on Pro means changing a row, not rewriting code.
